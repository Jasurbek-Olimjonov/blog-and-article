## Tech Stack & Approach

Built primarily with Bootstrap (flex and positioning utilities) to deepen 
hands-on experience with the framework. Custom SCSS handles the parts 
Bootstrap's utilities couldn't cleanly express — font staff, sizing and fine-grained positioning.
